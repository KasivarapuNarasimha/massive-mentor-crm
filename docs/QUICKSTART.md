# Massive Mentor — Quickstart (Post Milestone 0)

## One-Time Setup

```powershell
cd C:\Users\acer\massive-mentor

pnpm install
pnpm db:up
pnpm db:push
```

## Start Development

```powershell
pnpm dev
```

- Web: http://localhost:3000
- API: http://localhost:4000

See [DEVELOPMENT.md](../DEVELOPMENT.md) for full instructions.
